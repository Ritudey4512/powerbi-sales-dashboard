📊 Super Store Sales Dashboard & Forecasting
📌 Project Overview

This project analyzes the Super Store sales dataset using Power BI. The data was cleaned, transformed, and visualized to generate business insights. 
An interactive dashboard was developed to monitor sales performance, profitability, customer segments, shipping methods, and regional trends. 
A 15-day sales forecast was also created to predict future sales performance.

🎯 Objectives
 • Clean and preprocess raw sales data.
 • Analyze sales and profit trends.
 • Compare performance across different regions.
 • Identify top-performing categories and sub-categories.
 • Build an interactive dashboard for business decision-making.
 • Generate sales forecasts for future planning.

🛠 Tools & Technologies
 • Power BI
 • Power Query
 • DAX
 • Microsoft Excel
 • Data Visualization
 • Time Series Forecasting

📂 Dataset Information
  The dataset contains:
• Order Details
• Sales
• Profit
• Customer Segments
• Regions
• States
• Product Categories
• Shipping Modes
• Order Dates

🧹 Data Cleaning & Transformation
   The following preprocessing steps were performed:
• Removed duplicate records
• Handled missing values
• Corrected data types
• Created calculated measures using DAX
• Prepared date fields for time-series analysis

📈 Dashboard Features
  Executive KPIs---------------------------
• Total Orders
• Total Sales
• Total Profit
• Average Ship Days
  Sales Analysis-------------------------
• Sales by Payment Mode
• Sales by Region
• Sales by Customer Segment
• Sales by Category
• Sales by Sub-Category
• Sales by Shipping Mode
  Profit Analysis---------------------------------
• Monthly Profit Trends
• State-wise Profit Performance
  Geographic Analysis-----------------------------------
• Interactive map showing Sales and Profit by State
  Regional Filters--------------------------------------
Users can dynamically switch between:
• Central Region
• East Region
• South Region
• West Region
The dashboard automatically updates all visualizations based on the selected region.

🔮 Sales Forecasting
A separate forecasting dashboard was created to predict sales for the next 15 days.
Forecast Features-------------
• Historical Sales Trend Analysis
• Future Sales Prediction
• State-wise Sales Comparison
• Interactive Forecast Visualization

📊 Key Insights
• COD is the most preferred payment mode.
• Consumer segment contributes the highest sales.
• Office Supplies generate the largest sales among categories.
• Standard Class is the most commonly used shipping mode.
• Sales and profit vary significantly across regions and states.
